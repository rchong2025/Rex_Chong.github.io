THERMAL CONTROL / FSM
Embedded firmware2025

Programmable Reflow Oven

Converted a toaster oven into a programmable solder-reflow system with temperature acquisition, profile control, and user feedback.

8051 AssemblyADCPWMFSM
GitHub
More details

Goal

Build a controllable reflow process with customizable temperature stages and clear system feedback.

Implementation

  • Implemented a finite-state machine for configurable reflow profiles using 8051 assembly.
  • Read a thermocouple through cold-junction compensation and ADC-based temperature acquisition.
  • Controlled heater power through PWM and a solid-state relay.
  • Integrated LCD and speaker feedback, fault handling, an IR sensor, and motor-based automation.

Engineering focus

Embedded state management, sensor acquisition, temperature control, peripheral integration, and fault-aware behavior.

Magnetic Field Line-Following Robot

A two-controller robot with autonomous path following, Bluetooth communication, and manual control features.

PIC32STM32BluetoothPWM
GitHub
More details

Goal

Build a robot and controller that can follow a magnetic path, report progress, and support both autonomous and manual operation.

Implementation

  • Used PIC32 on the controller and STM32 on the robot.
  • Implemented joystick control and PWM-based speed control, plus reverse-path behavior.
  • Added two-way Bluetooth for statistics, location, path selection, and CSV path loading from a PC.
  • Integrated manual claw control, IR-triggered automatic pick/drop, battery indication, and controller audio feedback.

Engineering focus

Inter-controller communication, wireless data handling, motor control, mode management, and system feedback.

Tron Lightcycle Game

A retro-inspired game using memory-mapped I/O, timer and button interrupts, and a VGA pixel buffer.

CRISC-V AssemblyInterruptsVGA
GitHub
More details

Goal

Build a playable lightcycle-style game on a digital hardware platform, with input handling, score display, and collision logic.

Implementation

  • Used C and inline RISC-V assembly with memory-mapped peripherals.
  • Used a machine-timer interrupt and push-button interrupt for game timing and input.
  • Rendered the playfield through a VGA pixel buffer and used LEDs, switches, and seven-segment displays for I/O.
  • Implemented obstacle/collision handling and a simple AI opponent.

Engineering focus

Interrupt-driven programming, hardware register access, display rendering, and real-time game-state updates.

PIC32 Component Meter

A component-measurement system that combines PIC32 firmware with a Java desktop companion for serial logging and printing.

PIC32MX130CADCUARTJava
GitHub
More details

Goal

Measure electrical component values and make readings available on the device and in a desktop application.

Implementation

  • Measured signal period using the PIC32 core timer and used frequency-based calculations for capacitance and inductance.
  • Used ADC readings for resistance measurement and an LM335 temperature sensor for capacitance temperature compensation.
  • Displayed readings on an LCD and transmitted records over UART at 115200 baud.
  • Built a Java Swing companion using jSerialComm to receive readings, retain selected values, and print a formatted report.

Engineering focus

Timer-based measurement, ADC sensing, serial protocols, and integration between embedded firmware and a desktop GUI.
