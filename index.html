Temperature sensor

An ADC-based thermometer on the N76E003 that shows °C, °F, or K on an LCD, streams readings over UART, and plots them live in MATLAB.

8051 AssemblyADCUARTLCDMATLAB
GitHub
More details

Goal

Measure temperature from a sensor voltage, display it locally in a selectable unit, and log it to a PC as a live strip chart.

Implementation

  • Read a 12-bit ADC channel on the N76E003 and converted counts to voltage using 32-bit fixed-point math.
  • Converted the sensor voltage to temperature and calculated °C, °F, and K values for display.
  • Used a debounced push button to cycle through units and showed the reading and the input voltage on a 4-bit LCD.
  • Sent each reading over UART at 115200 baud, with the unit letter appended to every line.
  • Wrote a MATLAB script that parses the serial stream, plots a strip chart, and converts the plotted history when the unit changes.

Engineering focus

ADC acquisition, fixed-point arithmetic in assembly, button debouncing, serial communication, and PC-side data visualization.

Phasor Measurement & Calculator

An EFM8LB1 instrument that measures the amplitude, frequency, and phase difference of two signals, then lets you add, subtract, and multiply the stored phasors.

EFM8LB1C14-bit ADCTimer 2LCD
GitHub
More details

Goal

Measure a reference signal and a second signal, report their amplitudes, frequency, and relative phase, and perform basic phasor arithmetic on the results.

Implementation

  • Sampled two analog inputs with the EFM8LB1's 14-bit ADC, referenced to VDD.
  • Detected zero crossings in firmware and used Timer 2 to time the signal period and the delay between the two signals, giving frequency and phase.
  • Tracked each signal's peak with a slow decay so the amplitude readout follows changes.
  • Stored measurements in four slots chosen through digital inputs, with buttons to save, add, subtract, and multiply phasors.
  • Converted between polar and rectangular form using sin, cos, sqrt, and atan2 routines written from series and iterative approximations.
  • Showed live or stored results on a 16x2 LCD and a serial terminal, with a button to switch views.

Engineering focus

Time-based phase measurement, ADC sampling, numerical approximation on a resource-limited microcontroller, and user-interface handling in C.

Loan Amortization Calculator

A JavaFX desktop app that solves for an unknown payment or interest rate, builds a full amortization schedule, and prints or exports it.

JavaJavaFXNumerical methodsJava 2D printingCSSMSI installer
More details

Goal

Build a flexible loan calculator that works with real calendar dates, supports different payment and compounding periods, and produces a schedule that can be printed.

Implementation

  • Designed the interface in JavaFX with input fields, date pickers, drop-downs, and selectable Dark, Light, and Pink themes that are remembered between sessions.
  • Solved for an unknown payment or interest rate using a bisection search over a day-by-day simulation of compounding and payments.
  • Supported payments and compounding by day, month, or semi-month, with input validation for dates, amounts, and payment totals.
  • Added a Variable Dates window with an editable table, so the rate and payment can change partway through a schedule.
  • Generated the schedule as a text file and as a paginated print layout with yearly subtotals and a grand total.
  • Packaged the application as a Windows installer (.msi) using Advanced Installer, so it can be installed without a development setup.

Engineering focus

Object-oriented design across separate calculation, validation, output, and UI classes, numerical root finding, date arithmetic, desktop GUI development, and packaging software for distribution.
